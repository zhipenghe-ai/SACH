# Paper, framework and implementation mapping

This guide maps *Structure-aware contrastive hashing for unsupervised cross-modal retrieval* by Jinrong Cui, Zhipeng He, Qiong Huang, Yulu Fu, Yuting Li and Jie Wen, *Neural Networks* 174 (2024), 106211, to the corrected implementation. It uses the paper and its Fig. 1, which shares the supplied standalone diagram's layout and data flow. Phase 2C verifies the Phase 2B code. The numerical effect of the indexing correction on the published results remains unknown. [Paper](https://doi.org/10.1016/j.neunet.2024.106211)

## Reading Fig. 1

- The upper-left panel branches from images through the CNN to `V_I` and from text through Bag of Words to `V_T`. The modality MLPs produce compact descriptors `Z_I` and `Z_T`.
- The lower-left graph generator merges the modality affinities from the high-dimensional `V` features and the compact descriptors routed through “Deep Mine.” Section 3.3 specifies the threshold, spectral-clustering and fusion operations represented schematically in this panel.
- The middle panel has image and text GCN branches producing `G_I` and `G_T`. The cross-modal semantic alignment (CSA) arrows represent a contrastive learning objective between those branches. The cross-modal semantic integration (CSI) branch produces the joint `V_J`, which feeds `H_J` and joins the separate branches for `H_I` and `H_T`.
- The three relaxed representations feed the shared binary training code `B`. The two final hash functions use their own precomputed modality features and learn from `B` and similarity structure. The paper's equations specify the losses and optimization order.

## Verified corrections and interpretation

1. **Sample-ID indexing.** The teacher already gathered the coarse graph by dataset ID and recorded those IDs beside the code rows. The archived hash-function optimizer selected features in the recorded order but selected the graph target by contiguous positions. The corrected optimizer validates IDs, slices features and codes in collected order, and computes `S_cmm[ids[:, None], ids[None, :]]` for each batch. Every resulting entry refers to the two samples whose head outputs occur at that matrix position. The coarse graph values, definitions of the loss terms, loss weights and optimizer schedule are preserved. Equivalent targets give equivalent updates in controlled checks. A nontrivial permutation can change the graph loss, gradients and resulting head weights.
2. **Checkpoint persistence.** Best-head checkpoints now contain serialized `ImgNet` and `TxtNet` state dictionaries. CPU tests cover real writes, restore, directory isolation and failure propagation. The GPU smoke restored both heads and reproduced the same fixture retrieval outputs exactly. The strict rule for selecting a new best uses the sum of I→T and T→I MAP.
3. **Evaluation terminology.** Both directions report **MAP (full gallery)**. A fixture places the only relevant result beyond rank 50 in both directions and obtains the same scores from the original, Phase 2A and corrected evaluator. Existing retrieval arithmetic is preserved.

The active graph, normalization, DCL dependency and reduction, teacher and head objectives, optimization order, and NUS-WIDE batch choice still require author confirmation for any claim about the published runs. The controlled checks establish the software behavior described here. Benchmark-scale effect and full paper reproduction remain unverified.
